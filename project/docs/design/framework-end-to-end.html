Toàn cảnh

Sơ đồ framework end-to-end

Xương sống dọc: dữ liệu chảy từ scraper xuống bản CSV giao cho user. Ba cổng kim cương là điểm kiểm định; nhánh phải là nơi dữ liệu bị giữ hoặc trượt. Đường kẻ đứt ngang là ranh giới producer ↔ agent.

VÒNG 1 · BRONZE FRAMEWORK

Capture — trỏ vào HTML & chụp raw byte-exact

Chạy online mỗi 15′. Mục tiêu duy nhất: lấy toàn bộ mã nguồn HTML của trang chi tiết và lưu lại trước mọi xử lý. Điểm chèn là hook enrich() trong template-method của BaseScraper.run().

Trỏ vào URL bài

FRAMEWORK

Scraper lấy danh sách qua fetch_list() (RSS / reverse-API / HTML), parse_item() → Article, rồi dedup lớp 1 SHA-256(url+title) ở bảng seen_articles.

Cổng tuân thủ trước khi fetch

FRAMEWORK

★ Ghi raw — điểm bất biến của cả hệ

FRAMEWORK

RawStore.save(response) ghi response.content nguyên bytes qua .tmp → os.replace (atomic). Kèm .meta.json: header whitelist (loại Set-Cookie/Authorization), images[] quét read-only. Không decode, không normalize.

4

Bóc vùng con & chấm trạng thái chụp

FRAMEWORK

Chỉ SAU khi raw đã lưu: content_html = select_one(selector); miss → _density_extract (readability/goose3). _looks_complete kiểm ≥2048 bytes + node non-empty + không marker chặn → gán capture_status.

okpartial + incomplete_renderfailedskipped_robots
WORM
Write-Once-Read-Many. File .html là bytes nguyên của response, không bao giờ bị sửa. Vì raw lưu trước, parser hỏng có thể sửa và chạy lại offline trên artifact đã lưu — không cần hit lại site. sha256(file) == content_sha256 là bằng chứng provenance xuyên mọi tầng.
VÒNG 2 · SILVER FRAMEWORK

Standardize — làm sạch bằng kỹ thuật gì

SilverBuilder.build(meta, raw_bytes) là hàm THUẦN: chỉ nhận dict + bytes, không mạng, không đọc DB, không đọc clock. Cùng đầu vào → cùng Silver byte-for-byte, nên bump schema chỉ cần rederive_from_bronze.py.

GATE
Silver hard-gate. Trường bắt buộc: silver_schema_version, article_id, source_url, domain, content_sha256, cleaned_text, built_from_raw_path. Thiếu cleaned_text (minLength 1) ⇒ item held. structure/images là best-effort — lỗi không chặn cổng.
VÒNG 2 · CHANGE-DETECT FRAMEWORK

Log khi HTML đổi — 3 dấu vân tay, 5 trạng thái

Mỗi lần (re)capture ghi một hàng append-only vào article_versions. Ba dấu vân tay thuần/tất định phân biệt "bài đổi nội dung" với "trang đổi template" — quyết định bài đó có được re-extract, bỏ qua, hay đẩy sang người xem lại.

VÒNG 3 · HANDOFF FRAMEWORK AGENT

Agent handoff — ranh giới producer ↔ consumer

Producer chỉ export → validate → nghiệm thu. Agent (LLM provider bất kỳ do bạn điều khiển) là hộp đen, bị ràng buộc bởi hai JSON Schema. Handoff exactly-once: enqueue idempotent + claim atomic.

1

Phát packet

FRAMEWORK

agent_export.py claim item pending (BEGIN IMMEDIATE) → ghi data/agent_tasks/*.task.json. Packet trỏ raw qua raw_sha256, không nhúng bytes.

2

L1 — nhận diện thực thể từ TIÊU ĐỀ

AGENT

Chỉ dùng input.title. Xác nhận/bổ sung entity so máy dò code_first; mỗi surface phải là chuỗi con nguyên văn của title. Chấm 5 nhóm: ticker/etf/index/exchange/industry. Ghi l1-entity-output-v1.

method: exact_code / alias / semanticin_list · unlisted_candidatescitations ⊂ title
3

Bóc tách — phân tích BODY

AGENT

Phân tích cleaned_text. Sinh summary.abstractive + key_points, implication.text + impact_area, materiality.score + time_sensitivity; tuỳ chọn sentiment/event_type/entities. Ghi agent-output-v1.

bỏ bài nếu change_state ∈ {DRIFT, BROKEN}≥2 citations ⊂ cleaned_text · ≥20 ký tự
4

Nạp & chấm DoD

FRAMEWORK

agent_ingest.py verify precondition + schema + Definition-of-Done. Đạt → mark_done (agent_outputs); trượt → mark_failed + dod_reasons. Runtime không nhúng LLM.

DoD
Definition-of-Done (bóc tách) — mark_done ⇔ TẤT CẢ: ① schema PASS · ② ≥2 citations grounded ⊂ cleaned_text (≥20 ký tự) · ③ extraction_quality ∈ {high, medium} · ④ processing_metadata đủ. confidence đã bỏ khỏi gate (2026-08-18: self-report, calibration kém). L1 done = schema + grounding surface/citation ⊂ title.

Hợp đồng

Bất biến toàn hệ — checklist review

Bảy ràng buộc giữ cho hệ tái lập được và exactly-once. Vi phạm bất kỳ điều nào là lỗi kiến trúc, không phải lỗi cấu hình.

INV-1 · WORM

Raw byte-exact bất biến

File .html = response nguyên bytes; sha256(file) == content_sha256. Không bao giờ sửa.

INV-2 · PURE

Silver là hàm thuần của Bronze

Không network, không đọc DB, không now() (dùng fetch_ts) → re-derive giống hệt.

INV-3 · POINTER

Package trỏ raw, không inline

Tham chiếu qua raw_sha256; không nhúng bytes gốc — 1 nguồn sự thật.

INV-4 · GATE

Mọi package qua contract_validator

PASS mới pending; else held. Agent không bao giờ nhận dữ liệu chưa kiểm.

INV-5 · VERIFY

Agent verify raw_sha256

Kiểm trước khi xử lý (chống inject); output qua DoD mới done.

INV-6 · ONCE

Handoff exactly-once

Enqueue idempotent (UNIQUE(article_id, raw_sha256)) + claim atomic (BEGIN IMMEDIATE).

INV-7 · ≥2 CAP

Change-detect cần ≥2 capture/URL

refresh_watchlist cấp nguồn "lần chụp thứ 2" — nếu không, mọi bài kẹt ở NEW.
