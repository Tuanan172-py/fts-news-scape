Vietstock không cung cấp Public API. Các endpoint tìm được là **Internal API** (API nội bộ) được trang web sử dụng để tải các khối nội dung (partial views) như "Tin mới nhất", "Tin xem nhiều".
	• **Đặc điểm:** API trả về JSON chứa metadata đầy đủ (tiêu đề, ảnh, tóm tắt), nhưng **không hỗ trợ lọc theo mã chứng khoán (Symbol)** trực tiếp trong tham số gọi
