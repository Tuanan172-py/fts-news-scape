## Issues

- I1. `wave.conductor.ts` runs only on DSH, because `tools.agent_article`, `read` and `write` do not exist on OpenCode. The wave used the native adapter `opencode_native_run.py`. Proposed: promote it to an official `--runner opencode`.
- I2. `article_pack.py` has no `--before` flag; it only takes a single `--date`. The wave worked around it with `--exclude-file` holding 352 ids from 2026-10-01. The gap remains for later waves.
- I3. `token_ledger` wrote no new row and warned "Không có phiên DSH nào worker tạo sau mốc". It did not block the wave. Free-tier token cost was invisible; the only indirect measure was 88% context use.
- I4. The radar pointed at the wrong latest wave. W10011541 (15:41, 100 articles, finished, not from this session) appeared mid-wave. `--finish` verifies by the wave's article set, so the result was correct.
- I5. Proposed radar convention: anchor on the held wave (`--wave`), not on the maximum `created_epoch`, when several sources open waves.
- I6. The source that opened W10011541 was unknown. The L0 daemon does not open waves, so another session probably did. Check `ops_waves` before opening the next manual wave to avoid a packet race.
- I7. The backlog held duplicate content (Starship i27 and i28, NVL, PNJ, repeated gold-price bulletins). They were kept under ADR-0013 because frequency is a signal. Exemption from the LLM waited for the dedup P0 approval.
- I8. Context reached 88%. Every 500-article native wave hits the session ceiling, so the rule is one wave per new session plus a handoff, never two waves per session.
- I9. Packet archiving does not cover Article Lane. `project/data/agent_tasks/article/` held 148 `.task.json` packets from old waves, and `archive/20261001/` was empty.
- I10. Root cause of I9: `archive_completed_tasks` in `project/src/agent/archive.py` (lines 50 to 92) matches only the two legacy formats `<aid>.task.json` and `batch_*.task.json`. Article packets (`article_<wave>_NN.task.json`) match neither, so finish printed `archived: 0/500` and still exited 0.
- Proposed follow-up for I9 and I10, a separate normal-lane story with no data contract change:
  - Teach `archive_completed_tasks` the `article_*` family. When `--finish` exits 0, move `article_<wave>_*.task.json`, `.map.json`, `wave_<wave>.json` and `wave_<wave>.conductor.ts` to `archive/<YYYYMMDD>/W<wave>/`.
  - Keep outputs in `agent_outputs_article/` (about 100 KB per batch) as audit evidence. Archive packets (about 500 KB per batch) after DONE. Apply retention to `archive/`, for example 30 days then compress.
  - Show "packets not yet archived" on the radar so cleanup is measured.
