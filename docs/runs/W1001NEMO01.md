## Issues

- I1. `--repair` created duplicate batches. The second run produced both `r02` and `r01_r01` instead of only `r02`. Batch `r01` from the first repair was not run automatically and had to be run by hand.
- I2. `token_ledger` wrote nothing and warned "Không có phiên DSH nào worker tạo sau mốc". The OpenRouter runner does not use a DSH worker session, so the ledger found no matching session after the mark.
- I3. The last `r01_r01` batch timed out at 300 seconds. Coverage was already 99.4%, so the wave was not blocked.
- I1 and I2 were logged in `docs/OPEN-ITEMS.md` section E at the time: the duplicate-repair bug and the ledger gap for runners other than DSH.
